## 1. 项目概述

### 1.1 项目背景

本项目是一个个人技术平台，旨在展示个人技术文章、项目经验和专业技能，同时提供后台管理功能，方便内容管理和更新。

### 1.2 项目目标

- 打造个人技术品牌形象
- 提供技术文章分享平台
- 展示个人项目经验和技能
- 实现便捷的后台管理功能

### 1.3 目标用户

| 用户类型 | 描述 |
| :--- | :--- |
| 访客 | 浏览技术文章和项目案例的开发者 |
| 博主 | 平台所有者，管理和发布内容 |

### 1.4 术语定义

| 术语 | 说明 |
| :--- | :--- |
| 文章 | 技术博客文章，支持 Markdown 格式 |
| 项目 | 个人项目案例展示 |
| 分类 | 文章分类，用于组织文章 |
| 标签 | 文章标签，用于文章关联 |
| 技术栈 | 项目使用的技术列表 |

## 2. 功能需求

### 2.1 页面设计需求

| 类型 | 需求 |

## 3. 技术架构

### 3.1 前端技术栈

| 技术 | 版本 | 说明 |
| :--- | :--- | :--- |
| Vue | 3.5.x | 渐进式 JavaScript 框架 |
| Vite | 6.x | 下一代前端构建工具 |
| TypeScript | 5.8.x | JavaScript 超集，提供类型检查 |
| Naive UI | 2.44.x | Vue3 组件库 |
| Pinia | 3.x | Vue3 状态管理库 |
| Vue Router | 5.x | Vue3 官方路由管理器 |
| UnoCSS | 0.65.x | 原子化 CSS 引擎 |
| Axios | 1.15.x | HTTP 请求库 |
| Vditor | 3.11.x | Markdown 编辑器 |
| @vueuse/core | 14.x | Vue Composition API 工具库 |
| xicons | 0.13.x | 图标库 |
| pnpm | - | 包管理器 |

### 3.2 后端技术栈

| 技术 | 版本 | 说明 |
| :--- | :--- | :--- |
| Java | 21 | JDK 版本 |
| Spring Boot | 3.5.x | Spring 框架简化配置 |
| Jimmer | 0.9.x | Java ORM 框架 |
| PostgreSQL | - | 关系型数据库 |
| Redis | - | 缓存数据库 |
| Lombok | 1.18.x | 简化 Java 代码 |
| Maven | - | 项目构建工具 |

### 3.3 技术选型说明

| 选型 | 原因 |
| :--- | :--- |
| Vue 3 + Vite | 现代化前端框架，开发体验好 |
| Naive UI | Vue3 组件库，主题定制方便 |
| Jimmer | 新型 ORM，支持关联查询自动优化 |
| PostgreSQL | 可靠的开源关系数据库 |
| Redis | 高性能缓存，支持会话存储 |

## 4. 非功能性需求

### 4.1 性能需求

| 指标 | 要求 |
| :--- | :--- |
| 首屏加载时间 | ≤ 3秒 |
| API 响应时间 | ≤ 500ms |
| 并发用户数 | ≥ 100 |

### 4.2 兼容性需求

| 类型 | 要求 |
| :--- | :--- |
| 浏览器 | Chrome、Firefox、Safari、Edge 最新版本 |
| 响应式 | 支持 PC 端和移动端 |

### 4.3 安全需求

| 类型 | 要求 |
| :--- | :--- |
| 认证 | 后台管理需要登录认证 |
| 敏感数据 | 密码加密存储 |
| SQL注入 | 使用 ORM 防止注入 |
| XSS | 输入输出转义处理 |

### 4.4 部署需求

| 组件 | 要求 |
| :--- | :--- |
| 前端 | Nginx 托管静态资源 |
| 后端 | JAR 包部署 |
| 数据库 | PostgreSQL 13+ |
| 缓存 | Redis 6+ |
