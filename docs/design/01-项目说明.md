## 1. 项目概述

### 1.1 项目背景

本项目是一个个人技术平台，旨在展示个人技术文章、项目经验和专业技能，同时提供后台管理功能，方便内容管理和更新。

### 1.2 项目目标

- 打造个人技术品牌形象
- 提供技术文章分享平台
- 展示个人项目经验和技能
- 实现便捷的后台管理功能

### 1.3 目标用户

| 用户类型 | 描述 |
| :--- | :--- |
| 访客 | 浏览技术文章和项目案例的开发者 |
| 博主 | 平台所有者，管理和发布内容 |

### 1.4 术语定义

> 详见 [02-需求清单.md](./02-需求清单.md#12-术语定义)

## 2. 技术架构

### 2.1 技术选型说明

| 选型 | 原因 |
| :--- | :--- |
| Vue 3 + Vite | 现代化前端框架，开发体验好 |
| Naive UI | Vue3 组件库，主题定制方便 |
| Jimmer | 新型 ORM，支持关联查询自动优化 |
| PostgreSQL | 可靠的开源关系数据库 |
| Redis | 高性能缓存，支持会话存储 |

### 2.2 技术栈详情

> 详见 [02-需求清单.md](./02-需求清单.md#3-技术架构)

### 2.3 开发环境要求

| 组件 | 版本要求 |
| :--- | :--- |
| Node.js | ≥ 18.x |
| Java | ≥ 21 |
| PostgreSQL | ≥ 13.x |
| Redis | ≥ 6.x |

## 3. 项目结构

### 3.1 前端项目结构

```
ptp-frontend/
├── public/                     # 静态资源
├── src/
│   ├── api/                    # API 接口封装
│   ├── assets/                # 资源文件
│   ├── components/            # 公共组件
│   │   ├── admin/             # 后台管理组件
│   │   └── frontend/          # 前台展示组件
│   ├── icons/                 # 图标导出
│   ├── router/                # 路由配置
│   ├── stores/                # Pinia 状态管理
│   ├── views/                 # 页面组件
│   │   ├── admin/             # 后台管理页面
│   │   └── frontend/          # 前台展示页面
│   ├── App.vue                # 根组件
│   ├── main.ts                # 入口文件
│   └── style.css              # 全局样式
├── index.html                 # HTML 入口
├── package.json               # 项目配置
├── vite.config.ts             # Vite 配置
├── tsconfig.json              # TypeScript 配置
├── uno.config.ts              # UnoCSS 配置
└── .env / .env.production     # 环境变量
```

### 3.2 后端项目结构

```
ptp-backend/
├── src/
│   └── main/
│       ├── java/
│       │   └── cn/
│       │       └── jinynet/
│       │           └── ptp/
│       │               ├── PTechApplication.java  # 启动类
│       │               ├── api/                   # API 接口层
│       │               │   ├── admin/             # 后台管理接口
│       │               │   └── home/             # 前台公开接口
│       │               ├── config/               # 配置类
│       │               ├── service/              # 业务逻辑层
│       │               └── types/
│       │                   ├── entity/           # 实体类
│       │                   ├── enums/            # 枚举类
│       │                   └── dto/              # DTO 定义
│       └── resources/
│           ├── application.yml      # 主配置文件
│           ├── application-dev.yml  # 开发环境配置
│           └── application-prod.yml # 生产环境配置
├── pom.xml                     # Maven 配置
└── target/                     # 编译输出目录
```

### 3.3 目录规范

| 目录/文件 | 说明 |
| :--- | :--- |
| `api/` (前端) | 存放 API 接口封装，按业务模块拆分 |
| `components/` (前端) | 公共组件，按功能模块组织 |
| `views/` (前端) | 页面组件，按模块组织（admin/frontend） |
| `stores/` (前端) | Pinia store，每个 store 对应一个业务模块 |
| `api/` (后端) | API 接口层，遵循 RESTful 规范 |
| `service/` (后端) | Service 层，处理业务逻辑 |
| `types/entity/` (后端) | 实体类，与数据库表一一对应 |
| `types/dto/` (后端) | DTO 定义文件 |

| 文章页面 | 文章列表、文章详情、分类筛选、标签筛选、相关推荐 |
