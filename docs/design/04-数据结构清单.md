## 2. 系统设置表

### 2.1 system\_settings（系统设置表）

存储系统配置信息。

| 字段名            | 类型           | 约束                                                                | 说明                                   |
| :------------- | :----------- | :---------------------------------------------------------------- | :----------------------------------- |
| id             | BIGINT       | PRIMARY KEY, AUTO\_INCREMENT                                      | 主键ID                                 |
| setting\_key   | VARCHAR(100) | NOT NULL, UNIQUE                                                  | 设置键名，用于标识配置项                         |
| setting\_value | TEXT         | NULL                                                              | 设置值，存储配置内容                           |
| setting\_type  | VARCHAR(50)  | NOT NULL                                                          | 设置类型：string/text/number/boolean/json |
| description    | VARCHAR(255) | NULL                                                              | 设置项描述说明                              |
| category       | VARCHAR(50)  | NOT NULL                                                          | 配置分类：site/seo/security/other         |
| created\_at    | TIMESTAMP    | NOT NULL, DEFAULT CURRENT\_TIMESTAMP                              | 创建时间                                 |
| updated\_at    | TIMESTAMP    | NOT NULL, DEFAULT CURRENT\_TIMESTAMP ON UPDATE CURRENT\_TIMESTAMP | 更新时间                                 |

**索引**：

| 索引名                       | 字段           | 类型   |
| :------------------------ | :----------- | :--- |
| PRIMARY                   | id           | 主键   |
| uk\_system\_settings\_key | setting\_key | 唯一索引 |

### 2.2 配置项分类说明

| 分类       | 配置项               | 说明           |
| :------- | :---------------- | :----------- |
| site     | site\_title       | 网站标题         |
| site     | site\_description | 网站描述         |
| site     | site\_logo        | 网站Logo路径     |
| site     | site\_favicon     | 网站图标路径       |
| site     | site\_author      | 网站作者         |
| site     | site\_keywords    | 网站关键词        |
| seo      | seo\_title        | SEO标题        |
| seo      | seo\_description  | SEO描述        |
| seo      | seo\_keywords     | SEO关键词       |
| seo      | seo\_robots       | Robots.txt内容 |
| security | admin\_password   | 管理员密码（加密存储）  |
| security | session\_timeout  | 会话超时时间（分钟）   |
| security | login\_attempts   | 登录失败最大尝试次数   |
| other    | theme\_color      | 主题颜色         |
| other    | language          | 默认语言         |
| other    | timezone          | 时区设置         |

## 4. 文章管理表

| 字段名           | 类型           | 约束                                                                | 说明                         |
